Integrations

GIFs
Type /gif in the message box or click the GIF button to search. Without a key, searches go through your Commy account server, which never shares its key with the app. A key of your own is stored only on this device and is never sent to other members.
Stream Deck
Play soundboard sounds from your Stream Deck keys. Commy only listens for it on this computer, and asks you before a Stream Deck can connect.
  1. Download commy-soundboard.streamDeckPlugin from the latest Commy release and open it. Stream Deck 7.1 or newer installs it.
  2. Turn on the switch above, then drag Play sound from the Commy category onto a key.
  3. Pick a server and a sound in the key settings, and choose Allow when Commy asks.
IGDB
IGDB game database
Game search with cover art when tagging servers, and the proper title and cover for the game you are playing. Built in through your Commy account; add credentials here only if your account server does not offer game search.
  1. Sign in at dev.twitch.tv/console/apps (IGDB uses Twitch developer accounts; two-factor sign-in must be on).
  2. Choose Register Your Application. Any name works, OAuth Redirect URL http://localhost, Category Application Integration, Client Type Confidential.
  3. Open the app, copy the Client ID, press New Secret and copy the secret.
Saved only on this device, in its settings folder.

Server Rules

New members read and accept these before they can post. Markdown works: # headings, **bold**, *italics*, lists with - or 1., and links.

Auto Moderation

Every member's Commy app checks messages against these rules, including ones already posted. A message that breaks a rule is held: members don't see it and aren't notified, and moderators see it marked in the channel so they can deal with it. The owner and anyone who can manage messages or the server are never held. Currently: Off.

Blocked words

One word or phrase per line. Capitals and punctuation are ignored and whole words must match, so "ass" does not catch "class". End a word with * to catch every word that starts with it.

Spam

Mention limit
Hold messages that @mention more people than this, @everyone and @here included.
Flood limit
When someone posts faster than this in one channel, their extra messages are held.

Exempt roles

Members with these roles are never held.

Reports

Members can report people or messages to you as the owner. Reports arrive on this device only and are never shared with anyone else.
