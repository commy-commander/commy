Add a Bot

A bot runs as its own member on a computer or server that stays on, such as your PC, a home server or a small VPS. Commy does not host bots.

  1. Make an invite for the bot
    Bots join with an invite code, the same as people. Your app has to be online the first time the bot connects, because the bot only trusts a copy of the server it gets from the owner.
  2. Run it on the bot's computer
    Download commy-bot for that computer from the , unpack it, and run these in a terminal in that folder. The covers each system and building it yourself.
    Bringing a bot from somewhere else?
    Start the bot with the bridge instead, then connect your bot's code to it. The JavaScript library in the Commy source works like the common bot libraries: events such as messageCreate, and reply, react and role changes. Mentions and rich cards are converted for you.

Rules

Start a new server list?

Your account's current server list is replaced by the servers on this device. Only do this if none of your devices has the old list and you have no recovery code. Your other devices then get the new list from your account.

Bring back earlier servers

Your account server keeps earlier copies of your server list for 45 days, locked like the list itself. Bringing one back rejoins the servers it has that this device is missing. It never removes a server.

    Delete your account?

    Your account server deletes your account for good: your sign-ins, passkeys, two-step sign-in, linked devices, the locked copy of your server list, the invite links you made and your Discover listings. Every device signed in to it is signed out.

    This device also removes its copy of your servers, chats and settings for this account the next time Commy starts.

    Messages you already sent stay with the people and servers that received them, and servers you own keep running for their members. Encrypted copies on the sync service, which nobody else can read, expire within 90 days.

          Sync Server

          Where this server's messages sync
          Messages are locked on members' devices before they're sent, so the sync server can't read them. Most servers never need to move. Move only if your community wants its own sync server.
          1. Get a sync server. Set up your own, or use one run by someone you trust.

          File Backup

          Powered by Cloudflare
