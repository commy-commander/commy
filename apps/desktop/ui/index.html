Integrations

IGDB
IGDB game database
Optional. Adds game search with cover art when tagging servers, and shows the proper title and cover for the game you are playing. Everything works without it.
  1. Sign in at dev.twitch.tv/console/apps (IGDB uses Twitch developer accounts; two-factor sign-in must be on).
  2. Choose Register Your Application. Any name works, OAuth Redirect URL http://localhost, Category Application Integration, Client Type Confidential.
  3. Open the app, copy the Client ID, press New Secret and copy the secret.
